# StuApi
Secure Student Management System

This project demonstrates real-world backend security using JWT, Spring Security filters, and role-based authorization. The frontend communicates securely with the backend using token-based authentication similar to production systems.

Authentication
* Login system
* JWT token generation
* Token Stored in browser
* Token auto attached via Axios interceptor

Authorization 
* Role-based access (ADMIN)
* Protected APIs
* Security filter using JWT

Student Management
* View Students
* Add Student
* Update student
* Delete student

Deployment
* Backend deployed on Railway
* Frontend deployed on Netlify
* Environment variable used

Note:
* This is backend REST API
* frontend UI in another Repo
